### B-3 开场「跳过」点击不响应 —— 已修（代码级说明）
- **根因**：`_unhandled_input` 中 Web 全屏按钮热区 `Rect2(1166,14,44,44)` 与「跳过」热区 `Rect2(1152,18,110,40)` 重叠，且全屏判定排在 opening 分支之前——开场点击「跳过」右段（x≥1166）被全屏切换吞掉，Enter 因走键盘路径不受影响，与真浏览器实测现象吻合。
- **修法**：全屏热区判定加守卫 `phase != "opening"`（一行），开场期该区域只归「跳过」。（全屏按钮在开场画面本就不绘制，守卫无副作用。）
- headless 无法模拟浏览器点击命中，此项以代码级定位＋单行守卫修复交付，真浏览器复验并入试玩验收清单。
