原稿明确只跳过第5步；大声公清场不能自动完成引线可燃、鞭炮移至底座、横木松动。到大声公的图路不通（第1项）。「闲人」是否包含阿弟与扶轿人员也未定义（中）。

最小兼容：保留第2、3、4步及第6步；喇叭只替换第5步的安全调度窗口（清埕、停发锣），不替代阿弟离架与震源就位。路线为标旗→伞（开）→大声公，返程逆行。角色清场的细节不扩写设定，仅以安全窗口记账。正解仍保留小英背对的口径；备选用清场撤离保证她不在倒塌现场。**待主控裁定**。

## 4. 错误与计时：有漏洞（中）

- 潮鼓从初始主图即可到达，三次动作可达提前原死亡。若阿弟已扶轿，原文「阿弟未离开则失败」意味着不应仍写阿弟被砸死。兼容：鼓三下触发倒塌；未离架为死亡失败，已离架但未完整改命为未达安全闭环的回溯失败，不新增阿弟死亡描述。两种失败对白区分。**待主控裁定**。
- 横木在主图可达；第一次晃用于终局准备，第二次盲晃触发失控倒塌，以实现加速负反馈。一次正常晃不扣掉必需的安全操作机会。阈值为实现补充，**待主控裁定**。
- 一炷香默认240剧情秒，可配置加速；仅现实流逝，灵域暂停。超时未改命进入既定死亡/回溯逻辑；阿弟已避开时不虚构死亡。失败保留短暂亡者提示展示，随后自动重置至香点燃处；仅死亡分支由阿弟亡魂发言，安全未闭环分支由阿澄自语提示。**待主控裁定**。
- 花灯调查、纸马回头、第二铃不消耗必需步骤，不阻塞正解。章末花灯残骸照割痕，维持原剧情，不揭凶手。

## 复核总判定

**有漏洞，不能宣称原稿强连通或六步已无歧义。** 高风险集中在伞/喇叭孤岛、引线传火、移位后鞭炮可达与双物件终局顺序。采用上述显式兼容后可形成可玩闭环；这是工程验证的前提，仍待主控裁定设计补充。未改写原设计稿，也不扩大第二章。真人盲玩可读性、第二章意愿和定价接受度无法用自动冒烟代替。

## R1 实装细化记录（仍待主控裁定）

- 危险横木晃动每次减少45剧情秒，第二次过早晃动导致失败；满足安全前置后第一次晃为终局准备，准备后再晃同样视为失控，防止无限晃不受负反馈。45秒为工程阈值，并非原稿数字。
