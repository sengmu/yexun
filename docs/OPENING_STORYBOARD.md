# 《夜巡》第一章「分镜式动画开场」施工规格 v1

> 文档性质：施工规格，只定开场分镜、衔接与配套小改；不改任何定稿台词、剧情与数值口径。
> 立项依据：2026-11-17 用户首次真人试玩第一章即失败（试玩三问第一问未过），主控查明根因——点香后在现实对「横木」试技能，前置未齐时每晃扣 45 秒、晃两次灯架倒下直接失败（`game/main.gd` act() 的 `"beam"` 分支，现行约 1318–1332 行），而教程只教了「附身→回现实→按 E 试手」，没教两条保命规则。用户裁定：开场故事卡改做分镜式动画说明，讲故事＋规则教学＋引导入局；配套小改＝第一炷香首次误晃横木只警告不扣秒（见 §4）。
> 基线：远端 `main`（N-01 修复版，冒烟 1582 全绿）。本规格只覆盖第一章开场；二至六章无 opening 阶段，不受影响。

## 0. 定版约束（施工不得突破）

- **定稿不动**：现有 `CARD_TEXTS` 三卡原文逐字保留，分别落在本分镜的格 1、格 3、格 6（对照表见 §7），不改字、不换序。其余字幕均为新写，须与 `STORY_FULL.md`／`DESIGN_CH1_SLICE.md` v1.1 口径一致（阿澄之死＝发现主绳割痕后爬上戏台竹棚察看、雨后腐竹湿滑坠落的事故，非谋杀；本章不点破割绳者）。
- **SP 美术规格**：手绘 2D 水彩薄厚涂、低饱和灰蓝／雾青／褪色木色，红只作小面积点缀，夜景闷蓝灰、非纯黑。
- **零跳吓**：死亡格只用光闪＋声音抽离＋黑场一拍，不画坠落落地、不画遗体、不做突脸或骤响。
- **数值口径不变**：一炷香 240 秒、误晃扣 45 秒、两晃倒架（R6「试玩后可调」参数）均不借本单修改；§4 的宽容是一次性教学豁免，不是调参。
- **文字一律引擎排字**：所有字幕用现有 `text_at` 排字路径呈现；分镜图内不生成任何可辨读中文（见 §5 生图口径）。

## 3. 交互与衔接

- **推进**：沿用现有 opening 输入路径——点击／Enter／Space 调 `advance_opening()` 推进；每格动画未播完时点击＝跳到本格停帧，再点才进下一格（避免玩家连点误跳整格教学）。
- **跳过**：保留现有跳过语义不变——右上「跳过」热区 `Rect2(1152, 18, 110, 40)` 点击或 Esc → 直接 `start_game()`；R1 已修的守卫（`phase == "opening"` 时全屏钮不吞跳过点击）不得回归。跳过入口在每一格都可见、文案仍为「跳过」。
- **与 tutorial／explore 的衔接**：末格推进 → 现有 `start_game()` 原路径（`phase = "tutorial"`、`current = "incense"`、首句 `say()` 与 `append_tip("spirit", …)` 均不动）→ tutorial 完成转 explore → 玩家按 F `start_incense()`。格 9 与游戏首帧同图同构图，衔接处不加额外淡变。
- **跳过者补规则（兜底）**：跳过开场者在 `start_game()` 后、首次进入 explore 时，目标行下追加两条规则提示（走现有 `append_tip` 机制，新 key `rule_time`／`rule_beam`，一次性）：
- `rule_time`：「记住：灵域里时间是停的，想好了再回现实动手——现实里香在烧。」
- `rule_beam`：「记住：横木只能最后动。阿弟还在架下时晃它，灯架会提前倒——先救人，再动源。潮鼓也不能乱敲。」
看完开场者不重复弹（以「是否跳过」标志区分：完整看完置 `flags` 外的会话变量即可，不入存档）。
- **重试不重播**：`retry()` → explore 的现有路径不变，失败重试不重播开场；失败提示文案（现有 `hint_text()` failure 条）不动。
- **续玩**：标题页 C 续玩直接进存档阶段，不经过 opening，现状不变。

## 4. 配套小改：第一炷香首次误晃横木只警告不扣秒

单列本节，与分镜实现分开交付、分开验收。

- **改动位置**：`act()` 的 `"beam"` 分支末尾 else 子分支（现行约 1326–1330 行：`remaining -= 45`＋`shakes += 1`＋两晃 fail 的那一段）。其余子分支（未点香时的提示、`armed` 后再晃的 fail、前置齐备的 `armed = true` 正解路径）一律不动。
- **触发条件**（三项同时成立才豁免）：① 第一章（`chapter == 1`）；② 当前为本局第一炷香（`start_incense()` 每次调用即新的一炷——豁免按「每炷香一次」给，还是「仅本局第一炷」？**定版：仅本局第一炷香的第一晃**。理由：豁免的目的是让首试玩者活过第一次试错；重试后玩家已知规则，再给豁免会稀释规则二的教学）；③ 本炷香内横木误晃次数为 0（即这一晃是第一次）。
- **实现要点**：
- 新增会话级变量（如 `beam_grace_used`，布尔，默认 false）：在 `start_game()` 初始化为 false；第一炷香由 `start_incense()` 首次成功进入 playing 时置「可用」状态——实现上可用「`start_incense()` 被调用且 `beam_grace_used == false` 且尚未消耗」判定，或在 `start_game()` 直接置可用、首次误晃后置已用。**不得**把该标记放进 `flags` 存档字典（避免续玩读档把豁免带进后续炷香）；`retry()` 路径不重置该变量（重试即第二炷起，无豁免）。
- 豁免命中时：不扣 `remaining`、不递增 `flags.shakes`、不触发 fail；横木音效 `beam.wav` 照常；`say()` 改出警告文案（新写，须随交付过稿）：「横木猛地一晃，吱呀一声——好险。阿弟还在架下，这东西只能最后动，先把人救走。（第一次试错，不扣香）」——括号内元信息是否保留由过稿时定，倾向保留：让玩家明确知道这是教学豁免而非规则失效。
- 豁免用掉后，同炷香第二次误晃起完全恢复现行规则（-45 秒、`shakes` 计数、累计两晃 fail 不变）。
- **影响面**：仅第一章 playing 阶段 beam 的 else 子分支；潮鼓三下 fail、鞭炮、其余物件与二至六章（各自独立 `act*` 函数）不受影响；正解链第 6 步（前置齐备后晃横木置 `armed`）走的是另一子分支，不受影响；既有存档兼容（无新存档字段）。
- **与 §1 格 8 的关系**：开场已教规则二，本豁免是「教过仍试错」的兜底，不是替代教学；两者缺一不可（只教学不兜底，首试玩者仍可能两晃出局；只兜底不教学，玩家学不到规则）。

## 6. 实现要点与验收标准

### 6.1 实现要点（Godot）

- **数据驱动**：把 opening 从「`CARD_TEXTS` 索引」改为面板数据表（如 `OPENING_PANELS`：图源类型与路径／裁切区／镜头类型与参数／字幕行数组／音效键／建议时长），`advance_opening()` 的推进与结束判定（播完末格 → `start_game()`）逻辑不变、只换数据源。`phase == "opening"` 的状态名与输入路径不变。
- **镜头运动**：在 `_draw` 的 opening 分支按格内计时 `card_t` 计算——推近用纹理绘制 rect 的 scale 插值、平移用 region offset 插值、淡入淡出用全屏 `draw_rect` alpha 插值；不引入 Camera2D、不新增场景节点（与现行全程序化绘制架构一致）。
- **字幕排字**：复用 `text_at` 与现有卡面排字规格近似（主行 36 号、副行／小字 24／19 号），字幕置画面下部，压在现有 0.42 暗角层之上；定稿三卡在对应格以主行呈现，新写行作副行。
- **音效**：全部走现有 `play_fx`／ambience 通道与 `game/audio/` 库存，不新增音频文件；格间切换时环境声按 §1 表交叉淡变（ambience 双通道现有实现可复用）。
- **性能与体积**：新增 4 张 1280×720 图，沿用现有图片导入设置；Web 包体积增量须在交付报告中报数。
