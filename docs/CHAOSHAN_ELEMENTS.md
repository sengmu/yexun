## 三、待考证项（4，均不入正文定论）

1. **厝角头**：作为潮汕老厝屋角构件词通行，但其确切所指（山墙角做法／燕尾脊起翘部位）未查得权威辞书条目。本轮只在美术规格的意象层使用（「厝角头的起翘意象可入纹理」），不写术语定义。
2. **做尼、食茶**：通行潮汕口语，本轮未单独查得辞书级出处。已由方言白名单＋用量上限控制，风险低；后续可查《潮汕方言词典》补证。
3. **出花园日期的地域差**：府城正月十五与汕头、揭阳七月初七两路并行已核实；溪尾村为架空地名，本作按「明年之约」处理、不指定本村行礼日期，故不构成冲突，列此备查。
4. **善堂村级分堂的建制与簿册形制**：本作只用「施棺簿」这一功能性细节，簿册样式未考证，正文不描写簿册形制。
